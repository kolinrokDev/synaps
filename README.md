projects_module

Этот документ содержит структуру и содержимое кастомного модуля для Drupal, который:
Добавляет новый тип контента "Проект" (поля: название, описание, изображение, дата окончания).
Реализует блок, выводящий 3 последних проекта (для размещения на главной странице).
Добавляет REST-эндпоинт /api/projects (GET) с выводом в JSON.

Инструкция по запуску модуля.
Установка модуля:
-Поместите папку projects_module в директорию modules/custom/
-Установить модуль через панель админисратора или Drush 'drush en projects_module -y'
-Очистить кеш
Использование:
-Добавьте необходимые данные в Материалы->Проект
-Разместите блок в нужном регионе
-api/projects - возращает JSON со списком проектов

Архитектурные решения

Тип контента «Project».
Создаётся автоматически через hook_install() — это делает модуль переносимым и избавляет от необходимости ручной настройки на каждом окружении.
Тип включает:
-Заголовок
-Основное поле текста (body)
-Изображение (field_image)
-Дата окончания (field_end_date)

REST API.
-Реализован через custom‑controller (ProjectsController).
-REST-эндпоинт /api/projects -> роутинг projects_module.routing.yml
-контроллер ProjectsController

Блок «Последние проекты».
Реализован через LatestProjectsBlock:
-выводит 3 последних опубликованных проекта;
-использует entityQuery с accessCheck(TRUE);
-рендер формируется вручную через HTML-разметку;
-изображения выводятся через file_url_generator;
-шаблон подключается через library (projects_module_styles).
-Блок полностью контролируемый, лёгкий для кастомизации.

Стили.
Модуль подключает свою библиотеку стилей (projects_module.libraries.yml) и оформляет отображение через отдельный CSS.
